# 歌词演出参考与许可说明

本项目的歌词演出基于现有 Flutter 歌词时间轴实现。程序中的选择器
只使用本项目自己的中文模式名称，不以其他项目为 UI 功能名称。

## 原生实现
- 基础：原版滚动歌词
- 流光、云阶：已有的逐字辉光、错列排版
- 浮名：文字放大与镜头位移
- 心象：散落文字、焦点光环
- 群唱：多角色聊天气泡布局
- 倾诉：倾斜双行排版
- 镜台：多层透视板与浮动
- 时计：机械转盘指针
- 商籁：海报边框和文字编排
- 绘光：舞台光束
- 花火：彩色文字板与粒子火花
- 町景：街景剪影与霓虹字幕
- 莫奈：分栏画报
- 雾笺：雾窗与雨滴
- 回环：椭圆轨道与环绕动画
- 凝彩：双色块叠层
- 静止：低资源、无连续动画的三行展示

使用现有 LyricWord 时间戳进行高亮；没有逐字时间的 LRC
只以行级时间呈现，不会编造字级时间。
模式外观属于 Flutter 原生适配，不是 PC 上 WebGL/3D 特效的逐像素复制。
高开销的完整三维场景、物理模拟、按节拍识别等尚不等价；本文不会将
这些未实现的功能描述为已经完成。
